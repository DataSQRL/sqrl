[FATAL] [INVALID_SQRL_ADD_COLUMN] Column expression must directly follow the definition of table [Orders]
in script:plannerError-add-column-fail.sqrl [2:1]:
IMPORT ecommerceTs.orders;
Orders.col1 := (id + customerid)/2;
^
A column-addition statement does not directly follow the definition of the table it extends.

`TableName.new_col := expression;` must appear immediately after the `TableName := ...` definition (or after other column additions to the same table). Columns cannot be added to tables created with `CREATE TABLE` or imported from another script.

Erroneous code example:
```sql
EnrichedOrders := SELECT id, customerid, amount, tax FROM Orders;
LargeOrders := SELECT * FROM Orders WHERE amount > 100;
EnrichedOrders.total := amount + tax;
```

Move the column addition directly below the table definition:
```sql
EnrichedOrders := SELECT id, customerid, amount, tax FROM Orders;
EnrichedOrders.total := amount + tax;
LargeOrders := SELECT * FROM Orders WHERE amount > 100;
```

To add a column to a created or imported table, define a new table instead, e.g. `OrdersWithTotal := SELECT *, amount + tax AS total FROM Orders;`.

See https://docs.datasqrl.com/docs/main/errors#invalid_sqrl_add_column
